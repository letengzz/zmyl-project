## 考勤规则：四个打卡点均支持「迟到宽限」
- 需求：`打卡时间除了可以允许提前 也可以迟到宽限`；用户选择「全部四个打卡点」。
- 规则模型（`server/utils/attendance-rule.ts`）新增 3 个字段：`morningGrace`(默认15)、`morningEndGrace`(10)、`afternoonEndGrace`(10)；`afternoonGrace` 已有。
  - 上班判定：`t <= 标准时间 - 迟到宽限` → 按早到计入时间算，否则按标准上班时间算（上午与下午统一，默认值下与旧行为完全一致）。
  - 下班判定：晚于标准下班但不超过 `标准下班 + 迟到宽限` → 仍按标准下班算；超过 → 计加班（整点/半点取整）。
- 后端 `attendance-punch-import.post.ts`：合并 `effectiveMorningStart`/`effectiveAfternoonStart` 为统一 `effectiveStart`；`effectiveEnd` 增加 `endGrace`；上午下班改为允许加班（原为封顶不计加班）→ **行为变更**，已向用户说明。
- 前端 `attendance.vue`：设置弹窗上/下午各新增「上班迟到宽限」「下班迟到宽限」输入；`minuteRules`/`effectiveStart`/`effectiveEnd`/`ruleHelp`/`ruleFormPreview` 同步更新。
- 规则以 JSON 存于 `attendance_rule.rule_json`，新增字段通过 `normalizeRule` 自动补默认，**无需 DB 迁移**。
- 校验：ESLint 无新增错误；生产构建 `nuxt build` 通过。

## 考勤刷新：按当前规则重算当月工时
- 需求：`当调整了打卡规则设置后，点击刷新 也要同步把当前选择的月份根据每个人的考勤时间来重新计算`。
- 新增 `server/utils/attendance-calc.ts`：抽出纯计算（`parseTime`/`effectiveStart`/`effectiveEnd`/`roundToHalfHour`/`calcHours`/`RulePair`/`PunchTimes`）。
  - `attendance-punch-import.post.ts` 删除本地同名函数，改为 import 该模块 → 导入与重算**共用一份折算逻辑**（避免两套不一致）。
- 新增 `server/api/attendance-recalc.post.ts`：入参 `{ year, month }`；查出当月 `manual_times` 非空的 attendance 行，用当前规则 `calcHours` 重算 `manual_hours` 并写库。
  - 结果 >0 → 更新；=0 → 置 NULL（保留 `manual_times` 便于下次再算）；无变化不写库；统计 `updated/cleared/unchanged/skipped`。
- 前端 `attendance.vue`：`refreshAll()` 在 `fetchRule()` 之后、拉数据之前插入 `recalcMonth()`；工具栏刷新按钮旁新增 `recalcNotice` 提示条（显示重算结果，5s 后自动消失）。
- 说明：重算依据是库中已存的四个打卡时间点（`manual_times`）；原始打卡序列未持久化，故不重跑 `pickFour` 归属判定。手动录入若曾手动改写工时，刷新后也会按打卡时间重算。
- 校验：ESLint 无新增错误类型（新文件仅项目统一的 `no-explicit-any` 风格）；生产构建 `nuxt build` 通过。

## 考勤工时口径改为「完全按实际打卡时间」
- 需求：`考勤时长应该以实际的人员打卡时间来计算`。用户确认口径：**完全按实际打卡时间**（不取整/不保底/不封顶）+ **缺的时段不计**。
- `server/utils/attendance-calc.ts`：`calcHours(times)` 改为单参数实际时长 = 上午(me−ms) + 下午(ae−as_)；删除 `effectiveStart`/`effectiveEnd`/`roundToHalfHour`；`RulePair` 仅用于归属判定。
- `server/api/attendance-punch-import.post.ts`：`pickFour` 的 `DEFAULT` 改为全空 → **缺失的打卡点不再补 11:30/13:00 等默认时间**；无中午卡的兜底由 `first`/`DEFAULT` 改为 `''`；移除 `fmtMin` 导入；`calcHours(picked)`。
- `server/api/attendance-recalc.post.ts`：不再读取规则，直接 `calcHours(times)`。
- 前端 `attendance.vue`：删除 `effectiveStart`/`effectiveEnd`/`roundToHalfHour` 与半天逻辑；`effectiveTimes` 改为原始分钟数；`manualHours` = 实际时长；`DEFAULT_TIMES.afternoonEnd` 由 `endEarlyFrom` 改为 `stdEnd`（默认满勤 9h）；`ruleHelp`/`ruleFormPreview`/弹窗文案改为「工时按实际打卡时间计算，规则仅用于判定打卡时间归属」。
- 口径影响（已向用户提示）：3 次打卡（漏打下午上班卡）只算上午；**2 次打卡（仅上午上班+下午下班）工时为 0**，该天导入时会被清空（沿用 hours<=0 清空逻辑）。
- 设置项保留：「标准时间」用于 `pickFour` 归属判定；「允许提前/迟到宽限」仍影响 3 次/2 次打卡的归属判定，但不再影响工时数值。
- 校验：ESLint 无新增错误（未使用变量仍为既有的 `Select*` 5 个，`any` 数量不变）；生产构建 `nuxt build` 通过。
