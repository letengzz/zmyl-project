# 2026-10-08 工作日志

## 考勤管理：导入打卡时间后人员不显示的问题修复

需求：导入打卡时间（考勤报表-打卡时间）后，这些人也要出现在考勤管理的人员列表中。

根因：
- `attendance-punch-import.post.ts` 写入打卡时间时，INSERT 未写入 `punch_seq`（只写了 manual_hours/manual_times），而「只有打卡时间、无初始考勤」的人 `hours=0` 且 `punch_seq=NULL`。
- `attendance-persons.get.ts` 的人员筛选条件是 `(hours > 0 OR punch_seq IS NOT NULL)`，因此这些人被排除。
- 前端 `doPunchImport` 导入成功后只刷新了当前人员日历，未刷新人员列表。

改动：
1. `server/api/attendance-punch-import.post.ts`：INSERT 时一并写入 `punch_seq = 100000 + (i - 4)`（排在初始考勤人员之后）。
2. `server/api/attendance-persons.get.ts`：
   - 人员范围放宽为 `(hours > 0 OR manual_hours > 0 OR punch_seq IS NOT NULL)`，使历史已导入数据无需重新导入即可显示；
   - 增加 manual_hours / punch_seq 列存在性兜底（缺列自动补建）。
3. `app/pages/attendance.vue`：`doPunchImport` 成功后按报表 `dateRange` 切换到对应年月，并刷新人员列表（fetchPersons）+ 日历/加班/工资对比数据。

校验：ESLint 仅剩项目既有的 no-explicit-any 与模板样式告警，无新增问题。

## 考勤管理：新增「设置」— 可配置上下班标准打卡时间与允许时间

需求：考勤管理右上角加一个设置入口，可设置每个上下班的标准打卡时间及允许时间。

设计：把原先硬编码在前端 `attendance.vue` 与后端 `attendance-punch-import.post.ts` 的
MORNING_RULE / AFTERNOON_RULE 抽成可配置规则，存单行表 `attendance_rule`。

规则字段（9 个）：
- 上午：上班标准时间 / 上班允许提前(分钟) / 下班标准时间 / 下班允许提前(分钟)
- 下午：上班标准时间 / 上班允许提前(分钟) / 上班迟到宽限(分钟) / 下班标准时间 / 下班允许提前(分钟)

推导边界（默认值与原硬编码完全一致，回归零行为变化）：
- 上午 earlyBase=上班-提前=07:30，stdStart=上班=08:00，stdEnd=下班=11:30，endEarlyFrom=下班-提前=11:20
- 下午 earlyBase=上班-提前=13:00，lateLimit=上班-宽限=13:20，stdStart=上班=13:30，stdEnd=下班=18:00，endEarlyFrom=下班-提前=17:50
- 半天工时改为派生 (下午 stdEnd - earlyBase)/60 = 5h

改动：
1. 新增 `server/utils/attendance-rule.ts`：AttendanceRule 类型、DEFAULT_RULE、normalizeRule、
   parseHM/fmtMin、deriveMinuteRules、getAttendanceRule/saveAttendanceRule（首次访问 CREATE TABLE IF NOT EXISTS）。
2. 新增 `server/api/attendance-rule.get.ts` / `.post.ts`。
3. `attendance-punch-import.post.ts`：改为读取数据库规则，pickFour / effectiveMorningStart /
   effectiveAfternoonStart / calcHours 均改为按推导边界计算（函数改为接收 RulePair）。
4. `app/pages/attendance.vue`：
   - 新增 AttendanceRule 类型、DEFAULT_RULE、attendanceRule ref、minuteRules/MORNING_RULE/AFTERNOON_RULE/
     DEFAULT_TIMES 计算属性（原 const 改为 computed，引用处补 `.value`）；
   - 右上角新增「设置」按钮 + 打卡规则设置弹窗（含生效规则预览、恢复默认）；
   - 手动录入弹窗的「打卡规则」说明改为随规则动态生成（ruleHelp）；
   - onMounted 增加 fetchRule()。

注意：规则为全局单行配置（id=1）；`attendance_rule` 表由接口首次访问时自动创建，无独立迁移文件。
